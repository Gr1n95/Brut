# Brut
### Алгоритм подбора пароля методом перебора  

Учебный проект – оптимизированная реализация атаки полным перебором (brute force) для подбора паролей.
Программа наглядно демонстрирует принцип работы перебора, влияние длины пароля и размера алфавита на время взлома, а также показывает, как можно ускорить процесс с помощью параллельных вычислений.
## Особенности
* Гибкий набор символов – можно задать вручную или автоматически сузить до символов, входящих в целевой пароль (ускоряет поиск).

* Задействует все ядра процессора, распределяя поиск по длинам пароля.

* Оптимизированное сравнение – вместо создания строк для каждой комбинации сравниваются кортежи символов, что снижает нагрузку на память и CPU.

* Замер времени и количества попыток – позволяет оценить сложность взлома и сравнить эффективность.

* Автоматическое сужение алфавита – если не выбран кастомный набор, программа сама определит уникальные символы из целевого пароля, сокращая пространство поиска в разы.

## Требования

  Python 3.6 или выше
  Стандартные модули: itertools, string, time, multiprocessing 
  Никаких внешних зависимостей не требуется – всё работает из коробки.
